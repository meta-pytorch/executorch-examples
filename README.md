Example apps and demos using PyTorch's [ExecuTorch](https://github.com/pytorch/executorch) framework.

## Full applications

- [Muse Glimmer Voice Agent for macOS](https://github.com/meta-models/meta-oss-cookbook/tree/main/recipes/voice-agent-macos):
  an Apple silicon voice app that runs speech recognition, Muse Glimmer
  generation, and speech synthesis locally with ExecuTorch.
